  • super + t — open a tor browser window
  • super + f — open firefox (direct connection, outside tor)
  • super + q — close the active window
  • super + w — open network settings
  • super + k — open input settings
  • super + d — open display settings
  • ctrl + alt + t — open the terminal
  • super + shift + esc — shut down
  • sonic install <package>

apps installed with sonic and their session data stay in ram and are cleared when you shut down
